# 01: 普通用户查看本人详情

**What to build:** 让普通用户可以从现有用户列表点击自己的用户行，进入独立的只读详情页，并通过现有查询能力看到基础资料、账号状态、创建时间和更新时间。该切片同时建立详情请求的本人权限校验与主路径行为测试。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 普通用户点击自己的列表行后，以稳定用户 ID 进入独立详情页。
- [ ] 服务端确认目标用户 ID 与当前登录用户一致后才返回详情数据。
- [ ] 页面只读展示用户 ID、姓名或昵称、头像、邮箱、手机号、账号状态、创建时间和更新时间。
- [ ] 状态文案复用现有枚举；时间按宿主默认时区格式化为 `YYYY-MM-DD HH:mm`。
- [ ] 敏感字段沿用宿主系统现有脱敏和可见性规则。
- [ ] 自动化测试从登录身份和目标用户 ID 的高层行为缝验证列表入口、成功响应和详情展示。
