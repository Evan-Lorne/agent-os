# 02: 管理员查看任意用户并阻止越权

**What to build:** 在已经可用的详情主路径上，让现有管理员角色能够查看任意用户，同时确保普通用户、未登录用户或篡改目标 ID 的请求无法获得他人资料。

**Blocked by:** 01: 普通用户查看本人详情

**Status:** ready-for-agent

- [ ] 管理员身份由宿主现有登录态和角色体系识别，不新增独立白名单或权限模型。
- [ ] 管理员可从用户列表进入任意用户详情，并看到与本人详情相同范围的字段。
- [ ] 普通用户请求其他用户 ID 时返回 403 或宿主等价错误，响应不含目标用户字段。
- [ ] 未登录访问详情时按宿主认证规则拒绝，且不泄露用户信息。
- [ ] 前端对无权限入口的控制只改善体验，直接构造 URL 或请求仍由服务端拦截。
- [ ] 自动化测试覆盖管理员成功、普通用户越权、未登录访问及响应数据不泄露。
