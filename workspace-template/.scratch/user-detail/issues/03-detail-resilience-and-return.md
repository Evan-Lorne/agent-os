# 03: 完善详情异常状态与返回体验

**What to build:** 让用户详情在字段缺失、用户不存在或服务失败时仍提供一致、可恢复的体验，并在返回列表时保持用户原有的浏览上下文。

**Blocked by:** 01: 普通用户查看本人详情

**Status:** ready-for-agent

- [ ] 加载详情时展示明确加载状态，不显示上一次用户的残留数据。
- [ ] 任一约定字段为 `null`、空字符串或缺失时显示“暂无”，页面其余数据继续正常展示。
- [ ] 用户不存在时展示明确的 404 等价状态，并提供返回列表操作。
- [ ] 通用服务或网络错误时展示失败提示，并提供重试和返回列表操作；不得展示半份详情。
- [ ] 无权限状态展示明确提示，但不展示目标用户字段。
- [ ] 返回列表时保留宿主已支持的筛选、分页和滚动位置。
- [ ] 自动化测试覆盖加载、空字段、404、通用错误、重试及返回列表上下文。
