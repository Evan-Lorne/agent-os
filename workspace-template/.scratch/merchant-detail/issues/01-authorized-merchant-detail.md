# 01: 普通成员查看授权商家详情

**What to build:** 让普通成员从现有商家列表点击授权范围内的商家行，进入独立只读详情页，并通过现有 Merchant 查询能力看到基础资料、营业/账号状态、联系方式和创建/更新时间。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 点击商家列表行后，以稳定商家 ID 打开独立详情页并发起详情查询。
- [ ] 服务端确认当前成员拥有该商家的授权后才返回详情数据。
- [ ] 页面只读展示商家 ID、名称、已有基础资料、营业/账号状态、联系方式、创建时间和更新时间。
- [ ] 状态复用现有枚举文案，时间使用 `YYYY-MM-DD HH:mm` 和宿主默认时区。
- [ ] 空字段按统一规则显示“暂无”，敏感字段沿用宿主脱敏策略。
- [ ] 自动化测试从“登录身份 + 商家 ID”高层行为缝验证入口、授权成功响应和详情展示。
