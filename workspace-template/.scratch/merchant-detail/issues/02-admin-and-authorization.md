# 02: 管理员查看全部商家并阻止越权

**What to build:** 在普通成员主路径可用后，让现有管理员角色查看任意商家，同时确保普通成员访问授权范围外商家、未登录访问或篡改商家 ID 时无法获得商家资料。

**Blocked by:** 01: 普通成员查看授权商家详情

**Status:** ready-for-agent

- [ ] 管理员身份复用宿主现有登录态和角色体系，不新增白名单或权限模型。
- [ ] 管理员可从商家列表进入任意商家详情，并看到与普通成员相同范围的字段。
- [ ] 普通成员请求授权范围外商家 ID 时返回 403 或宿主等价错误，响应不含目标商家字段。
- [ ] 未登录或无有效角色访问详情时按宿主认证规则拒绝，且不泄露商家信息。
- [ ] 直接构造 URL 或请求修改商家 ID 仍由服务端鉴权拦截，不能依赖前端隐藏入口。
- [ ] 自动化测试覆盖管理员成功、授权外访问、未登录访问及响应数据不泄露。
