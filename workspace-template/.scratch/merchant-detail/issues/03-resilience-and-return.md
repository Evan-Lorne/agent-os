# 03: 完善商家详情异常与返回体验

**What to build:** 让商家详情在加载、字段缺失、商家不存在或服务失败时提供一致且可恢复的体验，并在返回商家列表时保留用户原有浏览上下文。

**Blocked by:** 01: 普通成员查看授权商家详情

**Status:** ready-for-agent

- [ ] 加载期间展示明确加载状态，不显示上一次商家的残留数据。
- [ ] 任一约定字段为 `null`、空字符串或缺失时显示“暂无”，其余数据仍可正常展示。
- [ ] 商家不存在时展示明确的 404 等价状态，并提供返回列表操作。
- [ ] 通用网络/服务错误时展示失败提示，并提供重试和返回列表操作；不得展示半份详情。
- [ ] 无权限状态展示明确提示，但不展示目标商家字段。
- [ ] 返回列表时保留宿主已支持的筛选、分页和滚动位置。
- [ ] 自动化测试覆盖加载、空字段、404、通用错误、重试及返回列表上下文。
